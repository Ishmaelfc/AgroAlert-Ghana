# Security Policy

## Reporting Security Issues

If you identify a security vulnerability, please report it privately before public disclosure.

Examples include:

- Exposure of credentials
- Unauthorized access issues
- Data privacy concerns
- Security weaknesses in deployment components

## Sensitive Information

Do not commit:

- API keys
- Authentication credentials
- Private datasets
- Service account files

## Research Data

Datasets included in this repository are intended for research reproducibility and demonstration purposes.
